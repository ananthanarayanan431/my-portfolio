Personal project, 2026.

- Built an AI debate-coaching application for the WeMakeDevs × Cognee Hackathon, featuring persistent per-user knowledge-graph memory that tracks argument history, reasoning patterns, and improvement areas across sessions.
- Designed a multi-agent coaching pipeline with LangGraph, using Cognee to build and query per-user knowledge graphs backed by Neo4j and pgvector for long-term semantic and relational memory.
- Implemented asynchronous task orchestration with Celery and Redis behind a FastAPI backend, enabling scalable, low-latency sessions with real-time feedback via OpenRouter.
